# Client Portfolio Service Manager — Next.js Copy

This folder is a Next.js copy of the current CPSM concept. The original static HTML/CSS/JS files remain in the repository root so the current working version is preserved.

## What was converted

- Client Portal dashboard
- Scope client filter concept
- Client Profile Directory search/results behavior
- Utilities import/export concept
- Workflow Center placeholder
- Project Management placeholder
- Financial Management placeholder
- Settings & Configuration placeholder
- Configure Client placeholder

## Run locally

```bash
cd cpsm-nextjs
npm install
npm run dev
```

Then open:

```text
http://localhost:3000/client-portal
```

## Notes

This is a front-end conversion copy. Client selection, Scope, and demo records currently use browser state and sample data. The next step is connecting these components to a database/API.
